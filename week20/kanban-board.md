# カンバンボード設計（GitHub Projects想定）

## カラム構成

- **To Do**：まだ着手していないタスク
- **In Progress**：現在作業中のタスク
- **Done**：完了したタスク

## 初期状態（開発開始前）

| To Do | In Progress | Done |
|---|---|---|
| ①タスクを作成できる | | |
| ④並び替え処理 | | |
| ②締め切り順に並び替えられる | | |
| ③就活/学校で分けて表示できる | | |
| ⑤タスクを編集できる | | |
| ⑥タスクを削除できる | | |
| 確認作業 | | |

## 運用ルール

- 各タスクは、対応するスプリント（Week22/23/24）が始まったら「To Do」に並べる
- 作業に着手したら「In Progress」に移動する
- 完成したら「Done」に移動する
- 1人で開発するため、同時に「In Progress」に置くカードは基本1枚とする（並行作業で混乱しないため）

## GitHub Projectsでの運用イメージ

1. リポジトリ（techmeets-month5）に「Projects」タブからボードを新規作成する
2. 上記3カラムを作成する
3. 各タスクをIssueとして登録し、カードとしてボードに追加する
4. スプリントごとに、該当するタスクのカードを「To Do」に並べる
